# 数据质量

## 字段和来源

上游省略值、负数占位符、无效日期保留为 `null`。真实 0 保留。各视频带 `source`、`collectedAt`。播放量、点赞、评论总数还各自带 `metricSources`。详情点赞数和评论响应总数单独采集，可能来自不同实例、缓存或采集时刻，暂无跨源平均或推算分数。

Invidious 搜索的发布时间可能按相对时间推算，详情可能只有日粒度。界面日期以 UTC 显示，采集和评论时间以浏览器本地时区显示。日粒度与估计值不宜用作精确发布时间。本轮同一个视频 ntDIxaeo3Wg 的搜索日期曾为 2026-03-23，详情日期为 2026-02-27，接近过滤边界时应点开详情核对。Piped 评论缺少绝对时间时显示原相对标签。文本转换保留分行，React 按纯文本渲染。

## 样本范围

搜索、日期和最小播放量过滤、排行榜仅覆盖已取记录。100 条目标可能需要 6–7 页，因为上游页间有重叠。跨源回退后仍按 video ID 去重。Invidious 关键词搜索通常没有明确 Shorts 分类。按类型过滤时只保留上游明确的分类，Piped 也可能不返回匹配的 Shorts。空结果只代表该次取样。时长不会被用作 Shorts 身份推断。

列表默认补齐前 3 条。其余记录可手动补齐。缺少评论数的记录会计入分布的“未知”桶，从评论互动率排行中排除。两站列表响应均未保证点赞或评论总数。

## 评论与字幕

评论分页按 ID 去重。Piped 支持默认顺序，最新选项会找有此能力的 Invidious。Invidious 的 `sort_by=new` 本轮有三例第一页的头条未改变且时间非单调。界面对已加载的最新评论按可用时间额外排序。游标仍沿用上游的原始遍历顺序。

评论关闭和失败分开处理。Piped 有显式关闭标志。Invidious 可用模糊 404 表示无评论或提取失败，后端尝试备用来源。如果两源均不可用则显示错误。

字幕目录成功返回空数组时显示上游未提供字幕。拿到目录但正文请求、解析失败时则显示提取错误。轨道自动类型来自上游标记，未提供时保留未知。VTT 与 TTML 使用毫秒时间戳。逐词样式和时间标签会从正文中清理，自动字幕轨道的滚动重复内容按原段保留。字幕回退会寻找同语言、且自动类型相容的轨道，响应显示实际来源。

## 指标

- **播放速度** = 播放量 ÷ 采集时已发布天数。小于 24 小时的记录单列。未来、缺失日期和缺失播放量不计算。
- **评论互动率** = 评论数 ÷ 有效非零播放量。仅用于内容筛选。
- 平均值、中位数和最大值取播放量已知记录。评论数和发布日期分布显示未知值。播放速度和评论互动率无法表示真实的参与率或视频质量。
